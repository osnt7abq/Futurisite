# IGLOO Website ❄️

A frosty, futuristic landing-page prototype inspired by an icy 3D
website concept.

## What's included

-   `igloo-website.html` --- the standalone website prototype.
-   `README.md` --- these project notes.

## Run the website

### Option 1: Open the HTML file

1.  Download or extract the project files.
2.  Open `igloo-website.html` in a modern browser such as Chrome, Edge,
    or Firefox.
3.  If the browser blocks any externally loaded assets, try the
    local-server option below.

### Option 2: Run a local server

If Python is installed, open a terminal in the project folder and run:

``` bash
python -m http.server 8000
```

Then open:

`http://localhost:8000`

Press `Ctrl+C` in the terminal to stop the server.

## Customize it

Open `igloo-website.html` in a code editor and look for the HTML, CSS,
and JavaScript sections. You can adjust the text, colors, spacing,
animations, and page sections there.

## Notes

-   This is a prototype inspired by the visual direction of the
    reference Reel, not an exact copy of the original website.
-   The standalone version does not require a React setup.
-   If you want more advanced, realistic 3D ice geometry and lighting,
    the next step would be to build a Three.js or React Three Fiber
    version.
